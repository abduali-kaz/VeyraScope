# VeyraScope

A terminal-based system information and network discovery toolkit for Linux Mint.

## Features

- Local system information
- Local network device discovery
- IP and MAC address inspection
- Bluetooth discovery
- Network service inspection
- Connectivity monitoring
- SSH and remote desktop tools
- Wake-on-LAN
- Scan comparison and CSV reports

Install Git and the required network tools:

sudo apt install git nmap
